เชื่อมต่อฐานข้อมูล

วาง URL ของเว็บแอป Google Apps Script ที่ได้จากการ Deploy (ลงท้ายด้วย /exec)

หา URL นี้ได้จากที่ไหน?
  1. เปิด Google Sheet ที่ใช้เก็บข้อมูล → ส่วนขยาย → Apps Script
  2. กด การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้
  3. คัดลอก URL ของเว็บแอป มาวางที่ช่องด้านบน
ผู้ดูแลเว็บใส่ URL ไว้ในไฟล์ config.js ได้ เพื่อไม่ต้องกรอกหน้านี้ในทุกเครื่อง
